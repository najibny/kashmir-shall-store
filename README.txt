كشمير شال — النسخة المعدلة للموبايل والتابلت

الملف الأساسي:
index.html
هذا الملف مستقل ويحتوي CSS وJavaScript بداخله حتى لا يعتمد العرض على تحميل style.css وscript.js عند فتحه محليًا على الهاتف.

الملفات:
- index.html: النسخة الجاهزة للتجربة
- style.css: نسخة CSS المنفصلة
- script.js: نسخة JavaScript المنفصلة
- logo.svg: شعار مؤقت مأخوذ من الشعار الموجود في المشروع الأصلي

مهم:
الشعار الأصلي الذي طلبه صاحب المشروع لم يكن موجودًا داخل الملف المضغوط المرفوع، لذلك logo.svg الحالي هو الشعار الموجود في النسخة الأصلية وليس الشعار الحقيقي إذا كان مختلفًا.
